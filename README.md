# Insurance Risk & Claim Analysis Dashboard

## Project Overview
This Power BI dashboard analyzes insurance claim data to identify risk patterns, claim trends, and customer insights.

The dashboard helps understand:
- Total claim amount
- Claim frequency
- Coverage zone analysis
- Car make analysis
- Age group insights
- Education & marital status impact

---

## Tools Used
- Power BI
- Data Cleaning
- Data Visualization
- Basic Data Analysis

---

## Dashboard Features
- Interactive filters
- KPI cards
- Pie charts
- Bar charts
- Trend analysis
- Customer demographic insights

---

## Key Insights
- Private car usage generated higher claim amounts.
- Highly urban areas showed significant claim values.
- Middle age groups had higher insurance claim amounts.
- Claim trends varied across car brands and education levels.
